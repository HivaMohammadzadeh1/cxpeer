This demo registers a small Claude-shaped peer, starts a real Codex peer through `cxpeer spawn`, sends it a message, and listens for both the answer and the idle notification. It records the wire frames locally so the interaction can be seen without a real Claude Code session.

Run it from this checkout after installing `cxpeer` and running `cxpeer install`:

```sh
python demo/demo.py
```
